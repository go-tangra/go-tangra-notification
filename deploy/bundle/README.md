# notification join bundle

Generated by the gateway (Gateway operations › Modules › notification › Add).

    docker compose up -d

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the channel-encryption key
(`GEN_KEY_1`: keep a copy, sealed channel settings cannot be opened without
it). Keep both on this host only. The enrolment token is valid for the
lifetime chosen in the wizard; after the first start the module renews its
identity itself.

The platform email relay is not configured by the wizard: add a
`platform_email` section to `config.yaml` (password from a mounted
`password_file`) if this instance delivers the platform's own mail.
